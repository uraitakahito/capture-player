# capture-player

The Web Capture viewer for BrowserHive WACZ files: WACZ files that conform to the
[BrowserHive WACZ Profile](https://uraitakahito.github.io/browserhive-specs/wacz-profile/1.28.0/).
It is a **modified version** of
[ReplayWeb.page](https://github.com/webrecorder/replayweb.page) 2.5.0 and
[wabac.js](https://github.com/webrecorder/wabac.js) 2.27.1 by Webrecorder, served
by a small Node server.

## Documentation

What it changes, how to run it, development, and following upstream — all on the
docs site:

- **English** — <https://uraitakahito.github.io/capture-player/>
- **日本語** — <https://uraitakahito.github.io/capture-player/ja/>

## Related Projects

- [replayweb-player](https://github.com/uraitakahito/replayweb-player) — serves the unmodified ReplayWeb.page, the other viewer Web Capture links to.
- [capture-ledger](https://github.com/uraitakahito/capture-ledger) — builds this image in the Web Capture dev stack and links each archive to both viewers.
- [browserhive-specs](https://github.com/uraitakahito/browserhive-specs) — the BrowserHive WACZ Profile this viewer reads.
